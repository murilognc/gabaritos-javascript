# Desenvolvimento em Javascript - Gabaritos das Listas de Exercícios

Repositório dedicado aos códigos-fonte e gabaritos das listas de exercícios desenvolvidas ao longo da disciplina de **Desenvolvimento em JavaScript**. 

O objetivo deste espaço é fornecer aos estudantes os exemplos práticos resolvidos, servindo como material de apoio para estudos, revisão e fixação dos conteúdos abordados em aula.

---

## Estrutura do Repositório

As pastas estão organizadas por lista de exercícios. Dentro de cada lista, há subpastas correspondentes a cada exercício individual (`exercicio-01`, `exercicio-02`, etc.):

```text
repositorio-javascript/
 ┣ lista-01/
 ┃ ┣ exercicio-01/
 ┃ ┃ ┣ index.html

```

## Como Executar os Exercícios

Existem duas formas simples de rodar e testar os códigos deste repositório:

### Opção 1: Utilizando a extensão *Live Server* no VS Code (Recomendado)

Esta opção é ideal para simular um servidor local e atualizar a página automaticamente sempre que você salvar alterações no código.

1. Abra o Visual Studio Code.
2. Certifique-se de instalar a extensão **Live Server**.
3. Abra a pasta principal do repositório no VS Code (`File > Open Folder...`).
4. Navegue até a pasta do exercício desejado (ex: `lista-01/exercicio-01`) e abra o arquivo `index.html`.
5. Clique no botão **"Go Live"** localizado no canto inferior direito da barra de status do VS Code, ou clique com o botão direito no código HTML e selecione **"Open with Live Server"**.

### Opção 2: Abrindo diretamente no navegador

Se preferir uma abordagem direta sem ferramentas adicionais:

1. Localize a pasta do repositório no explorador de arquivos do seu computador.
2. Navegue até a pasta da lista e do exercício desejado (ex: `lista-01/exercicio-01`).
3. Dê um **duplo clique** no arquivo `index.html` para abri-lo diretamente no seu navegador padrão (Google Chrome, Firefox, Edge, etc.).
4. *Dica:* Para visualizar mensagens no console ou depurar o código, pressione `F12` (ou clique com o botão direito > **Inspecionar**) e vá na aba **Console**.
